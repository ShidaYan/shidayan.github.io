# YAN Shida Personal Website

This is a lightweight static personal academic website.

## Files

- `index.html`: page structure and text content
- `styles.css`: layout, beige minimalist academic style, and responsive design
- `script.js`: small footer year script

## What to update next

1. Save your portrait photo in this folder as profile-photo.jpg to replace the fallback initials.
2. Add profile links such as Google Scholar, GitHub, LinkedIn, and your CV PDF.
3. Refine the short research statement in the About Me section.
4. Complete the final venue details for the TGAT paper.

## Preview

Open `index.html` directly in a browser, or serve the folder with any local static server.
